# 简单直播间测试示例

这是一个简单的示例项目，用于测试 bili-live-danmu 库连接真实直播间。

## 快速开始

### 1. 发布主库到本地 Maven

在主项目根目录运行：

```bash
cd ../../..
./gradlew publishToMavenLocal
```

### 2. 运行测试

回到此目录：

```bash
cd examples/simple-test
./gradlew run
```

### 3. 修改房间号

编辑 `src/main/java/cn/liqing/example/SimpleLiveRoomTest.java`：

```java
long roomId = 3;  // 改成你想测试的房间号
```

- 确保已安装 Java 21
- 确保房间号对应的直播间正在直播
